VIKASH KUMAR PORTFOLIO - COMPLETE FILES
Admin (URL)
http://localhost/portfilo1/portfolio_mysql_admin_xampp/portfolio_mysql_admin/login.php


Files:
- index.html: portfolio page
- style.css: website styling
- myimage.png: VK Vikash Kumar logo from your provided image
- profile.png: profile photo from your provided image

LOCAL XAMPP SETUP:
1. Copy this whole folder into C:\xampp\htdocs\portfolio (or use the files in your existing project folder).
2. Ensure Apache is Running in XAMPP.
3. Open http://localhost/portfolio/
4. Keep index.html, style.css, myimage.png and profile.png together in the same folder.
5. If you want the Resume button to work, put your PDF file named Resume.pdf in this same folder.

Note: This is the frontend portfolio. It does not automatically connect to the separate MySQL admin dashboard.
